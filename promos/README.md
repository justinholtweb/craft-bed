# Plugin Store promo images

Marketing images for the Bed listing on the Craft Plugin Store, rendered in the same theme as the
plugin's marketing page at
[justinholt.com/plugins/craft-bed](https://justinholt.com/plugins/craft-bed).

## Building

```bash
./build.sh          # all slides
./build.sh "2 5"    # just slides 2 and 5
```

Output lands in `out/` as `bed-promo-N.png`, 1920×1080 (rendered at 2× in headless Chrome, then
downsampled so the type stays crisp).

## Notes

Bed is **free with no editions**, so unlike the paid plugins in the family there is no price on the
cover badge and no figure anywhere in the deck that a pricing change could strand.

The **watermark is an outline, not the filled mark**. Filled, the bed is a wide slab with one small
hole in it, and at 1180px across a slide it reads as a hard-edged grey box laid over the artwork
rather than as a bed — the same trap as Abacus's frame bars, Awesemo's chest box and Bandage's
plaster. Strip the mass, keep the line.

Two layout rules the deck was retuned for after the first render:

- **The copy column has to fit above the footer, and beside the panel.** The panel starts at
  `left: 900px` and the copy column is 780px inside a 130px gutter, so a bullet that wraps to two
  lines both runs into the panel and pushes the last point onto the footer lockup — and nothing
  clips, the text simply lands on top. Two-line headings, three-or-four-line ledes, and one line
  per bullet (about 60 characters at 25px).
- **`.points li` is a flex container.** An inline `<span class="mono">` or `<em>` left loose in the
  text becomes a *sibling flex item* and picks up the 16px gap on both sides. Every point keeps its
  text in one `<span class="t">`.

`fonts.css` is generated by `build.sh`, which base64-inlines the two woff2 files in `assets/` —
Chrome's `file://` origin rules block them otherwise. It is gitignored; don't edit it.
